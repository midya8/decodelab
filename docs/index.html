03 / NORMALIZE BEFORE THE CUTOFF

A nucleus is mass, not a score.

Order here: stable temperature, normalized top-k, then the smallest normalized top-p prefix reaching the threshold. Equal base probabilities use lexical token order. Other libraries can choose different ties or composition rules.

The bug this replaces

The earlier sampler summed p^(1/T) before normalization to decide the nucleus. With probabilities (0.6, 0.3, 0.1), T=0.5 and top-p=0.7, its powers sum to 0.46, so it kept all tokens. After normalization the first token alone has 0.7826 mass and is the complete nucleus. Direct powers could also all underflow; subtracting the maximum log probability first leaves at least one exponential equal to one. Very small tails can still round to zero.

Top-k changes the reference mass too: (0.6, 0.3) renormalizes to (2/3, 1/3). At top-p=0.65 the first token alone qualifies. Neither cutoff is a judgment about truth.

05 / SEARCH IS NOT AN ORACLE

Inspect what the beam threw away.

These beams use unfiltered conditional model log probability, not the sampling controls. Finished EOS paths compete with live paths and remain in the beam. No length penalty, separate finished pool or early-stopping heuristic is used. The exhaustive oracle has the same EOS/cap objective.

06 / BOUNDS AND PRIOR WORK

Likelihood is not a writing review.

Exhaustive enumeration is exponential and deliberately bounded. This browser allows two symbols, six generation steps and beam widths 1-3. The Python enumerator has explicit depth, vocabulary and node limits and returns no partial certificate on overflow. All numbers use floating point, not exact real arithmetic.

Independent checks use 90-digit Decimal temperature powers, rational path products and rational forward probability propagation. The browser separately recomputes all staged distributions, finite outcomes and beam candidates. Fixtures are reproducible examples, not human evaluation. Diversity and repetition statistics do not establish coherence, factuality or safety. No training, learned model or new decoding algorithm is claimed.
